# C++ for Software Engineering & Quantitative Finance

Author: Shreejit Verma

C++ is the primary language for **High Frequency Trading (HFT)**, **Game Engines**, and **Low-Latency Systems**.

## 📌 Learning Path

### 1. The Basics (C++98/03)
- Pointers & References (Critical!)
- Memory Management (Stack vs Heap)
- OOP (Virtual functions, vtables)

### 2. Modern C++ (C++11/14/17/20) - **MUST KNOW**
- **Smart Pointers:** `std::unique_ptr`, `std::shared_ptr` (See `01-Modern-Cpp-for-Quants`)
- **Move Semantics:** `std::move`, R-value references.
- **Multithreading:** `std::mutex`, `std::atomic`, Lock-free programming basics.
- **Lambda Expressions:** Closures.

### 3. Low Latency / Quant Specifics
- **Cache Locality:** Structure of Arrays (SoA) vs Array of Structures (AoS).
- **Branch Prediction:** `likely` / `unlikely`.
- **Compile Time Magic:** Templates, `constexpr`, SFINAE, Concepts.

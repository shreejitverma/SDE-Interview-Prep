# Complete C++: Zero to Godhood

A multi-volume C++ guide that runs from C++98/03 foundations through C++26, then into advanced systems programming and specialized mastery topics.
Each chapter lives in its own folder under a volume; superseded drafts sit in `_archive/` folders and are not part of the book.

## How to read it

- Full table of contents: [SUMMARY.md](SUMMARY.md), generated from the chapter files by `tools/gen_book_summary.py`.
- Start at [Volume 01](Volume_01_Foundation_C98_03/) if you are new to C++, or jump to the standard you need.
- Reference material and interview cheat sheets are in [Appendices](Appendices/).

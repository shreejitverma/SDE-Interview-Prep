\hypertarget{thread-pools}{%
\section{1. Thread Pools}\label{thread-pools}}

Spawning threads is expensive (syscall, stack allocation). Thread pools
reuse threads.

\begin{lstlisting}[language={C++}]
// Basic concept
class ThreadPool {
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    std::mutex mtx;
    std::condition_variable cv;
    // ...
};
\end{lstlisting}

\hypertarget{the-actor-model}{%
\section{2. The Actor Model}\label{the-actor-model}}

No shared state. Actors communicate via messages.

\begin{itemize}
\tightlist
\item
  Each Actor has a mailbox (queue) and a thread (or shared thread pool).
\item
  Eliminates locking issues by design.
\item
  Frameworks: CAF (C++ Actor Framework).
\end{itemize}

\hypertarget{disruptor-pattern}{%
\section{3. Disruptor Pattern}\label{disruptor-pattern}}

Ring buffer based, high-throughput, low-latency inter-thread messaging.
Used in HFT.

\begin{itemize}
\tightlist
\item
  Pre-allocated memory (avoid GC/allocations).
\item
  Single Writer / Multiple Reader or Multiple Writer scenarios.
\item
  Uses memory barriers/fences instead of locks.
\end{itemize}

\hypertarget{coroutines-for-concurrency}{%
\section{4. Coroutines for
Concurrency}\label{coroutines-for-concurrency}}

Using C++20 Coroutines to write async code that looks sync.

\begin{lstlisting}[language={C++}]
Task<int> async_algo() {
    int a = co_await fetch_a();
    int b = co_await fetch_b();
    co_return a + b;
}
\end{lstlisting}

\hypertarget{false-sharing}{%
\section{5. False Sharing}\label{false-sharing}}

When two threads write to different variables that happen to sit on the
same cache line.

\textbf{Fix:} \passthrough{\lstinline!alignas(64)!} (typical cache line
size).

\begin{lstlisting}[language={C++}]
struct alignas(64) PaddedCounter {
    std::atomic<int> val;
};
\end{lstlisting}

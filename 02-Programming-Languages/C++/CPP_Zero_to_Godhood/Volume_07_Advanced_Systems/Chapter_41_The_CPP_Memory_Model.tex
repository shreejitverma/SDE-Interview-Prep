\hypertarget{the-c-memory-model}{%
\section{1. The C++ Memory Model}\label{the-c-memory-model}}

Defined in C++11. It guarantees that if you have a data race, you have
Undefined Behavior.

\textbf{Data Race:} Two threads access the same memory location
concurrently, at least one is a write, and they are not synchronized (no
mutex, no atomics).

\hypertarget{atomic-operations}{%
\section{2. Atomic Operations}\label{atomic-operations}}

\passthrough{\lstinline!std::atomic<T>!} ensures individual
read/modify/write operations are indivisible.

\begin{lstlisting}[language={C++}]
std::atomic<int> count = 0;
count++; // Thread-safe fetch-add
\end{lstlisting}

\hypertarget{memory-orderings}{%
\section{3. Memory Orderings}\label{memory-orderings}}

This is where C++ becomes ``Godhood'' level.

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline!memory\_order\_relaxed!}: No ordering
  guarantees. Just atomicity.
\item
  \passthrough{\lstinline!memory\_order\_acquire!}: (Load) Subsequent
  reads/writes stay after this load.
\item
  \passthrough{\lstinline!memory\_order\_release!}: (Store) Prior
  reads/writes stay before this store.
\item
  \passthrough{\lstinline!memory\_order\_acq\_rel!}: Both.
\item
  \passthrough{\lstinline!memory\_order\_seq\_cst!}: (Default)
  Sequential Consistency. Global total ordering. Expensive.
\end{itemize}

\hypertarget{synchronizes-with}{%
\subsection{3.1 Synchronizes-With}\label{synchronizes-with}}

If Thread A stores with \passthrough{\lstinline!release!} and Thread B
loads with \passthrough{\lstinline!acquire!}, everything A did before
the store is visible to B after the load.

\begin{lstlisting}[language={C++}]
std::atomic<bool> ready = false;
int data = 0;

void producer() {
    data = 42;
    ready.store(true, std::memory_order_release); // "Publish" data
}

void consumer() {
    while (!ready.load(std::memory_order_acquire)); // Wait and "Acquire"
    assert(data == 42); // Guaranteed to see 42
}
\end{lstlisting}

\hypertarget{fences}{%
\section{4. Fences}\label{fences}}

\passthrough{\lstinline!std::atomic\_thread\_fence!}. Used to enforce
ordering without an atomic operation, or to combine with
\passthrough{\lstinline!relaxed!} operations.

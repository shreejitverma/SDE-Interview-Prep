\hypertarget{fold-expressions}{%
\section{1. Fold Expressions}\label{fold-expressions}}

Simplifies variadic template unpacking. No more recursion needed for
basic operations.

\hypertarget{unary-folds}{%
\subsection{1.1 Unary Folds}\label{unary-folds}}

\begin{lstlisting}[language={C++}]
template<typename... Args>
auto sum(Args... args) {
    return (... + args); // Unary left fold: ((arg1 + arg2) + arg3) ...
}

int result = sum(1, 2, 3, 4); // 10
\end{lstlisting}

\hypertarget{binary-folds}{%
\subsection{1.2 Binary Folds}\label{binary-folds}}

\begin{lstlisting}[language={C++}]
template<typename... Args>
void print(Args... args) {
    (std::cout << ... << args) << "\n"; // (cout << arg1) << arg2 ...
}
\end{lstlisting}

\hypertarget{class-template-argument-deduction-ctad}{%
\section{2. Class Template Argument Deduction
(CTAD)}\label{class-template-argument-deduction-ctad}}

Compiler deduces template arguments for class templates from the
constructor.

\begin{lstlisting}[language={C++}]
#include <vector>
#include <tuple>
#include <mutex>

// C++14: Types explicit
std::pair<int, double> p1(1, 3.14);
std::vector<int> v1 = {1, 2, 3};
std::lock_guard<std::mutex> lk(mtx);

// C++17: Types deduced
std::pair p2(1, 3.14); // pair<int, double>
std::vector v2 = {1, 2, 3}; // vector<int>
std::lock_guard lk2(mtx); // lock_guard<mutex>
\end{lstlisting}

\hypertarget{user-defined-deduction-guides}{%
\subsection{2.1 User-Defined Deduction
Guides}\label{user-defined-deduction-guides}}

Sometimes the compiler needs help to deduce the correct type.

\begin{lstlisting}[language={C++}]
template<typename T>
struct Wrapper {
    T value;
    Wrapper(T v) : value(v) {}
};

// Deduction guide: "If constructed with const char*, deduce string"
Wrapper(const char*) -> Wrapper<std::string>;

Wrapper w("hello"); // Wrapper<std::string>, not Wrapper<const char*>
\end{lstlisting}

\hypertarget{auto-non-type-template-parameters}{%
\section{\texorpdfstring{3. \texttt{auto} Non-Type Template
Parameters}{3. auto Non-Type Template Parameters}}\label{auto-non-type-template-parameters}}

Templates can deduce the type of non-type parameters.

\begin{lstlisting}[language={C++}]
template<auto Value>
void print_value() {
    std::cout << Value << "\n";
}

int main() {
    print_value<42>();   // Value is int 42
    print_value<'c'>();  // Value is char 'c'
}
\end{lstlisting}

\hypertarget{stdinvoke}{%
\section{\texorpdfstring{4.
\texttt{std::invoke}}{4. std::invoke}}\label{stdinvoke}}

Uniform way to invoke any callable (function pointer, functor, lambda,
member function pointer).

\begin{lstlisting}[language={C++}]
#include <functional>

struct Foo {
    void bar(int i) { std::cout << "Foo::bar " << i << "\n"; }
    int data = 10;
};

void free_func(int i) { std::cout << "free_func " << i << "\n"; }

int main() {
    Foo f;
    
    // Call member function
    std::invoke(&Foo::bar, f, 1); 
    
    // Access member data
    std::cout << std::invoke(&Foo::data, f) << "\n";
    
    // Call free function
    std::invoke(free_func, 2);
}
\end{lstlisting}

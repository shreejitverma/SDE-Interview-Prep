\hypertarget{stdmdspan}{%
\subsubsection{\texorpdfstring{1.
\texttt{std::mdspan}}{1. std::mdspan}}\label{stdmdspan}}

A non-owning multidimensional view over contiguous memory. It is the
cornerstone for modern C++ linear algebra and scientific computing,
allowing you to treat a flat \passthrough{\lstinline!std::vector!} as a
2D, 3D, or ND matrix.

\begin{lstlisting}[language={C++}]
#include <mdspan>
#include <vector>

std::vector<int> data = {1,2,3,4,5,6};
// View data as a 2x3 matrix
std::mdspan matrix(data.data(), 2, 3);

matrix[1, 2] = 42; // Uses C++23 multidimensional subscript
\end{lstlisting}

\hypertarget{stdflat_map-and-stdflat_set}{%
\subsubsection{\texorpdfstring{2. \texttt{std::flat\_map} and
\texttt{std::flat\_set}}{2. std::flat\_map and std::flat\_set}}\label{stdflat_map-and-stdflat_set}}

Node-based containers (\passthrough{\lstinline!std::map!},
\passthrough{\lstinline!std::set!}) have terrible cache locality. Flat
containers provide the same API but are backed by contiguous
\passthrough{\lstinline!std::vector!}s, meaning binary search lookup is
highly optimized for the CPU cache.

\begin{lstlisting}[language={C++}]
#include <flat_map>

std::flat_map<int, std::string> cache_friendly_map;
cache_friendly_map[1] = "A"; // O(N) insert, but O(log N) cache-friendly lookup
\end{lstlisting}

\hypertarget{new-range-adaptors}{%
\subsubsection{3. New Range Adaptors}\label{new-range-adaptors}}

C++23 dramatically expands the \passthrough{\lstinline!<ranges>!}
library. * \textbf{\passthrough{\lstinline!views::enumerate!}}:
Python-like index + value iteration.
\passthrough{\lstinline!cpp     for (auto [index, value] : std::views::enumerate(vec)) \{ ... \}!}
* \textbf{\passthrough{\lstinline!views::zip!}}: Iterate over multiple
ranges simultaneously. * \textbf{\passthrough{\lstinline!views::chunk!}
/ \passthrough{\lstinline!views::slide!}}: Process ranges in blocks or
sliding windows.

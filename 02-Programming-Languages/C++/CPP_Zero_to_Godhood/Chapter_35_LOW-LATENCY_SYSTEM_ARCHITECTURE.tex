\hypertarget{the-disruptor-pattern-c-implementation}{%
\subsection{24.1 The Disruptor Pattern (C++
Implementation)}\label{the-disruptor-pattern-c-implementation}}

A high-performance inter-thread messaging library. Key concept:
\textbf{Single-Writer Ring Buffer} with no locks.

\begin{lstlisting}[language={C++}]
template<typename T, size_t Size>
class Disruptor {
    std::array<T, Size> ring_buffer;
    alignas(64) std::atomic<int64_t> cursor{-1}; // Cache line padded
    
public:
    template<typename F>
    void publish(F&& factory) {
        int64_t current = cursor.load(std::memory_order_relaxed);
        int64_t next = current + 1;
        
        // Write data (no contention for single writer)
        factory(ring_buffer[next & (Size - 1)]);
        
        // Commit
        cursor.store(next, std::memory_order_release);
    }
    
    // Consumer tracks its own sequence...
};
\end{lstlisting}

\hypertarget{kernel-bypass-networking-concept}{%
\subsection{24.2 Kernel Bypass Networking
(Concept)}\label{kernel-bypass-networking-concept}}

Standard OS networking (interrupts, context switches) adds 10-50us
latency. \textbf{Solution}: Map the NIC (Network Interface Card)
directly to user-space memory (DPDK, Solarflare OpenOnload).

\begin{itemize}
\tightlist
\item
  \textbf{Zero Copy}: Packet data goes from NIC -\textgreater{} CPU L3
  Cache -\textgreater{} User Buffer.
\item
  \textbf{Polling}: Instead of interrupts, one CPU core spins
  (\passthrough{\lstinline!while(true)!}) checking the NIC ring.
\end{itemize}

\hypertarget{os-tuning-for-c}{%
\subsection{24.3 OS Tuning for C++}\label{os-tuning-for-c}}

Your code is only as fast as the OS allows.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{CPU Isolation (\passthrough{\lstinline!isolcpus!})}: Isolate
  cores from the OS scheduler so your thread never gets preempted.
\item
  \textbf{Huge Pages}: Use 2MB or 1GB pages to reduce TLB (Translation
  Lookaside Buffer) misses.
  \passthrough{\lstinline!cpp     void* ptr = mmap(NULL, size, PROT\_READ|PROT\_WRITE,                       MAP\_PRIVATE|MAP\_ANONYMOUS|MAP\_HUGETLB, -1, 0);!}
\item
  \textbf{Disable C-States}: Prevent CPU from going to sleep (power
  save) which causes wake-up latency.
\end{enumerate}

\hypertarget{lmax-disruptor-internals}{%
\subsection{24.5 LMAX Disruptor
Internals}\label{lmax-disruptor-internals}}

The key to Disruptor's speed is the \textbf{Sequence Barrier}.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Cursor}: Monotonically increasing number (atomic).
\item
  \textbf{Barrier}: Consumers wait until
  \passthrough{\lstinline!cursor >= my\_sequence!}.
\item
  \textbf{Wait Strategy}:

  \begin{itemize}
  \tightlist
  \item
    \passthrough{\lstinline!BusySpinWaitStrategy!}: Loops
    \passthrough{\lstinline!while(cursor < seq)!}. 100\% CPU, 0ns
    latency.
  \item
    \passthrough{\lstinline!YieldingWaitStrategy!}: Loops but calls
    \passthrough{\lstinline!std::this\_thread::yield()!}.
  \item
    \passthrough{\lstinline!BlockingWaitStrategy!}: Uses
    \passthrough{\lstinline!std::condition\_variable!} (slowest).
  \end{itemize}
\end{enumerate}

\hypertarget{python-bindings-pybind11}{%
\subsection{35.1 Python Bindings
(pybind11)}\label{python-bindings-pybind11}}

Bridging the gap between Python's ease of use and C++'s raw power. *
\textbf{The Problem:} Python objects are ref-counted
(\passthrough{\lstinline!PyObject*!}). C++ has RAII. Who owns the
pointer? * \textbf{Return Value Policies:} *
\passthrough{\lstinline!py::return\_value\_policy::copy!}: Python gets a
copy (Safe). *
\passthrough{\lstinline!py::return\_value\_policy::reference!}: Python
references C++ memory (Dangous if C++ deletes it). *
\passthrough{\lstinline!py::return\_value\_policy::take\_ownership!}:
Python takes over \passthrough{\lstinline!delete!}.

\begin{lstlisting}[language={C++}]
#include <pybind11/pybind11.h>
namespace py = pybind11;

struct Pet {
    std::string name;
    Pet(const std::string &name) : name(name) { }
};

PYBIND11_MODULE(example, m) {
    py::class_<Pet>(m, "Pet")
        .def(py::init<const std::string &>())
        .def_readwrite("name", &Pet::name);
}
\end{lstlisting}

\hypertarget{java-native-interface-jni}{%
\subsection{35.2 Java Native Interface
(JNI)}\label{java-native-interface-jni}}

The bridge to the Enterprise (and Android). * \textbf{Cost:} Crossing
the JVM boundary is expensive (pointer chasing, pinning objects). *
\textbf{Pitfall:} \passthrough{\lstinline!JNIEnv*!} is thread-local. Do
not share it between threads. * \textbf{Local References:} JNI creates
local refs for every object returned. If you don't
\passthrough{\lstinline!DeleteLocalRef!} in a loop, the JVM OOMs.

\begin{lstlisting}[language={C++}]
extern "C" JNIEXPORT jstring JNICALL
Java_com_example_MyClass_nativeMethod(JNIEnv *env, jobject thiz) {
    return env->NewStringUTF("Hello from C++");
}
\end{lstlisting}

\hypertarget{stable-c-abi}{%
\subsection{35.3 Stable C ABI}\label{stable-c-abi}}

To speak to Rust, C\#, or Go, use the lingua franca: C. *
\textbf{\passthrough{\lstinline!extern "C"!}}: Disables C++ name
mangling (e.g., \passthrough{\lstinline!\_Z3foov!} becomes
\passthrough{\lstinline!foo!}). * \textbf{Struct Layout:} Use
\passthrough{\lstinline!StandardLayoutType!} structs (no virtuals, all
public).

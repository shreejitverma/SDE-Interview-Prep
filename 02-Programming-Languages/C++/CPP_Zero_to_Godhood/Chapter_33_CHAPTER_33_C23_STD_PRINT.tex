\hypertarget{stdprint-and-stdprintln}{%
\subsection{\texorpdfstring{1. \texttt{std::print} and
\texttt{std::println}}{1. std::print and std::println}}\label{stdprint-and-stdprintln}}

C++ finally gets high-performance, type-safe, and readable console
output, replacing \passthrough{\lstinline!printf!} and
\passthrough{\lstinline!iostream!}.

\hypertarget{basic-usage}{%
\subsubsection{1.1 Basic Usage}\label{basic-usage}}

\begin{lstlisting}[language={C++}]
#include <print>

int main() {
    int id = 42;
    std::string name = "Alice";

    std::println("User {} has ID {}", name, id);
    // Output: User Alice has ID 42
}
\end{lstlisting}

\hypertarget{performance}{%
\subsubsection{1.2 Performance}\label{performance}}

\passthrough{\lstinline!std::print!} writes directly to the
unicode-aware buffer, avoiding stream overhead and allocation. It is
often faster than \passthrough{\lstinline!printf!}.

\hypertarget{formatting}{%
\subsubsection{1.3 Formatting}\label{formatting}}

Uses the same format specifications as
\passthrough{\lstinline!std::format!} (C++20).

\begin{lstlisting}[language={C++}]
std::println("Pi: {:.2f}", 3.14159); // Pi: 3.14
std::println("Hex: {:#x}", 255);     // Hex: 0xff
\end{lstlisting}

\hypertarget{output-to-streams}{%
\subsubsection{1.4 Output to Streams}\label{output-to-streams}}

\begin{lstlisting}[language={C++}]
#include <fstream>

std::ofstream file("log.txt");
std::println(file, "Error code: {}", 500);
\end{lstlisting}

\hypertarget{stdspanstream}{%
\subsection{\texorpdfstring{2.
\texttt{std::spanstream}}{2. std::spanstream}}\label{stdspanstream}}

A stream wrapper around a fixed buffer
(\passthrough{\lstinline!std::span!}), replacing the deprecated
\passthrough{\lstinline!std::strstream!}. No allocation.

\begin{lstlisting}[language={C++}]
#include <spanstream>
#include <iostream>

char buffer[128];
std::spanstream ss(buffer);

ss << "Hello " << 123;
std::string_view result = ss.span(); // "Hello 123"
\end{lstlisting}

\hypertarget{relaxed-constexpr}{%
\section{1. Relaxed constexpr}\label{relaxed-constexpr}}

C++11 \passthrough{\lstinline!constexpr!} functions were extremely
limited (single return statement). C++14 removed most restrictions.

\hypertarget{what-is-allowed}{%
\subsection{1.1 What is Allowed?}\label{what-is-allowed}}

\begin{itemize}
\tightlist
\item
  Local variable declarations (not static/thread\_local).
\item
  Mutation of local objects.
\item
  Control flow statements (\passthrough{\lstinline!if!},
  \passthrough{\lstinline!switch!}, loops).
\item
  Multiple return statements.
\end{itemize}

\begin{lstlisting}[language={C++}]
// C++11 Style (Recursive, single expression)
constexpr int factorial11(int n) {
    return n <= 1 ? 1 : n * factorial11(n - 1);
}

// C++14 Style (Imperative, readable)
constexpr int factorial14(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

static_assert(factorial14(5) == 120, "Math check");
\end{lstlisting}

\hypertarget{binary-literals}{%
\section{2. Binary Literals}\label{binary-literals}}

Native support for binary representation.

\begin{lstlisting}[language={C++}]
int b1 = 0b101010; // 42
int b2 = 0b1111'0000; // 240 (with separator)
\end{lstlisting}

\hypertarget{digit-separators}{%
\section{3. Digit Separators}\label{digit-separators}}

Use single quotes (\passthrough{\lstinline!'!}) to make large numbers
readable.

\begin{lstlisting}[language={C++}]
long long billion = 1'000'000'000;
double pi = 3.14159'26535;
unsigned int address = 0xDEAD'BEEF;
\end{lstlisting}

\hypertarget{deprecated-attribute}{%
\section{\texorpdfstring{4. \texttt{{[}{[}deprecated{]}{]}}
Attribute}{4. {[}{[}deprecated{]}{]} Attribute}}\label{deprecated-attribute}}

Mark functions, classes, or variables as deprecated.

\begin{lstlisting}[language={C++}]
[[deprecated("Use newFunc() instead")]]
void oldFunc() {}

void foo() {
    oldFunc(); // Compiler warning
}
\end{lstlisting}

\hypertarget{semantic-analysis-types-scopes}{%
\subsection{18.3 Semantic Analysis (Types \&
Scopes)}\label{semantic-analysis-types-scopes}}

Before generating code, we must validate it.

\textbf{Symbol Table:}

\begin{lstlisting}[language={C++}]
struct Symbol { string type; };
using Scope = map<string, Symbol>;
vector<Scope> scopes; // Stack of scopes

void enter_scope() { scopes.push_back({}); }
void exit_scope() { scopes.pop_back(); }
\end{lstlisting}

\textbf{Type Checking:} Recursively visit the AST. *
\passthrough{\lstinline!BinaryExpr!}: Check left.type == right.type. *
\passthrough{\lstinline!Variable!}: Check if exists in symbol table.

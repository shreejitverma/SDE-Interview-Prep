\hypertarget{c11-functional-programming}{%
\chapter{C++11 FUNCTIONAL
PROGRAMMING}\label{c11-functional-programming}}

C++11 brought functional programming paradigms to the language, centered
around Lambdas.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{lambda-expressions}{%
\section{1. LAMBDA EXPRESSIONS}\label{lambda-expressions}}

Lambdas are anonymous function objects.

\hypertarget{syntax}{%
\subsection{1.1 Syntax}\label{syntax}}

\passthrough{\lstinline![ captures ] ( params ) -> ret \{ body \}!}

\begin{lstlisting}[language={C++}]
auto add = [](int a, int b) { return a + b; };
int sum = add(1, 2);
\end{lstlisting}

\hypertarget{captures}{%
\subsection{1.2 Captures}\label{captures}}

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline![]!}: No capture.
\item
  \passthrough{\lstinline![=]!}: Capture everything by value (copy).
\item
  \passthrough{\lstinline![\&]!}: Capture everything by reference.
\item
  \passthrough{\lstinline![x]!}: Capture x by value.
\item
  \passthrough{\lstinline![\&x]!}: Capture x by reference.
\end{itemize}

\begin{lstlisting}[language={C++}]
int factor = 10;
auto multiply = [factor](int n) { return n * factor; }; // factor captured by value
\end{lstlisting}

\hypertarget{mutable-lambdas}{%
\subsection{1.3 Mutable Lambdas}\label{mutable-lambdas}}

By default, value captures are \passthrough{\lstinline!const!}. Use
\passthrough{\lstinline!mutable!} to modify them.

\begin{lstlisting}[language={C++}]
int x = 0;
auto increment = [x]() mutable { return ++x; }; // x is internal state
\end{lstlisting}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{stdfunction}{%
\section{2. STD::FUNCTION}\label{stdfunction}}

\passthrough{\lstinline!std::function!} is a polymorphic wrapper for
\emph{any} callable (function pointer, lambda, functor, bind result).

\begin{lstlisting}[language={C++}]
#include <functional>

void print(int i) { std::cout << i; }

std::function<void(int)> func;
func = print;
func = [](int i) { std::cout << i * 2; };
\end{lstlisting}

It has runtime overhead (virtual function call, possible allocation).
Prefer templates or auto if possible.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{stdbind}{%
\section{3. STD::BIND}\label{stdbind}}

\passthrough{\lstinline!std::bind!} performs partial application of
functions.

\begin{lstlisting}[language={C++}]
#include <functional>
using namespace std::placeholders;

int sub(int a, int b) { return a - b; }

// Bind second argument to 5
auto sub5 = std::bind(sub, _1, 5); 
// sub5(10) calls sub(10, 5) -> 5
\end{lstlisting}

\textbf{Note:} Lambdas mostly replaced
\passthrough{\lstinline!std::bind!} in modern C++ because they are
clearer and faster (compiler optimization).

\hypertarget{stdmdspan}{%
\subsubsection{\texorpdfstring{1.
\texttt{std::mdspan}}{1. std::mdspan}}\label{stdmdspan}}

A multidimensional non-owning span with a layout policy. The
\passthrough{\lstinline!operator[i, j]!} from C++23 is directly used
here. It is the cornerstone for modern linear algebra.

\begin{lstlisting}[language={C++}]
#include <mdspan>
std::vector<int> v(12);
auto view = std::mdspan(v.data(), 3, 4);
view[1, 2] = 99;
\end{lstlisting}

\hypertarget{flat-containers}{%
\subsubsection{2. Flat Containers}\label{flat-containers}}

\begin{itemize}
\tightlist
\item
  \textbf{std::flat\_map / std::flat\_set}: Sorted associative
  containers backed by contiguous storage (vectors). They offer
  drastically better cache performance for read-heavy workloads compared
  to tree-based maps.
  \passthrough{\lstinline!cpp     \#include <flat\_map>     std::flat\_map<std::string, int> m;      m["a"] = 1;!}
\end{itemize}

\hypertarget{extensive-range-updates}{%
\subsubsection{3. Extensive Range
Updates}\label{extensive-range-updates}}

C++23 dramatically expands the \passthrough{\lstinline!<ranges>!}
library with new views and algorithms. * \textbf{std::ranges::to}:
Converts any range into a specified container type, with optional
nesting.
\passthrough{\lstinline!cpp     auto v = std::views::iota(0, 5) | std::ranges::to<std::vector>();!}
* \textbf{New Views}: * \passthrough{\lstinline!views::enumerate!}:
Yields index/value pairs. * \passthrough{\lstinline!views::zip!}:
Iterate over multiple ranges simultaneously. *
\passthrough{\lstinline!views::chunk!} /
\passthrough{\lstinline!views::slide!}: Process ranges in blocks or
sliding windows. * \emph{Others}: \passthrough{\lstinline!adjacent!},
\passthrough{\lstinline!cartesian\_product!},
\passthrough{\lstinline!join\_with!}, \passthrough{\lstinline!repeat!},
\passthrough{\lstinline!stride!}.
\passthrough{\lstinline!cpp     for(auto [i, x] : std::views::enumerate(v))\{ std::println("\{\}: \{\}", i, x); \}!}
* \textbf{New Algorithms}: \passthrough{\lstinline!fold\_left!},
\passthrough{\lstinline!fold\_right!},
\passthrough{\lstinline!contains!},
\passthrough{\lstinline!find\_last!},
\passthrough{\lstinline!starts\_with!}.
\passthrough{\lstinline!cpp     auto sum = std::ranges::fold\_left(v, 0, std::plus\{\});!}

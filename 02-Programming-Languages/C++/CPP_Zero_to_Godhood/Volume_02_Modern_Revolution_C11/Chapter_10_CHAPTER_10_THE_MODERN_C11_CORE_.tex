\subsection{1. Type Inference \& Safety}\label{type-inference-safety}}

\hypertarget{auto-automatic-type-deduction}{%
\subsubsection{\texorpdfstring{1.1 \texttt{auto}: Automatic Type
Deduction}{1.1 auto: Automatic Type Deduction}}\label{auto-automatic-type-deduction}}

C++11 introduced \passthrough{\lstinline!auto!} to let the compiler
deduce the type of a variable from its initializer.

\begin{lstlisting}[language={C++}]
auto i = 42;        // int
auto d = 3.14;      // double
auto s = "hello";   // const char*
auto& ref = i;      // int&
const auto* ptr = &i; // const int*
\end{lstlisting}

\textbf{Crucial Rules:} 1. \textbf{Reference Dropping:}
\passthrough{\lstinline!auto!} drops top-level references and
\passthrough{\lstinline!const!} by default (like template deduction).
\passthrough{\lstinline!cpp     int x = 0;     int\& y = x;     auto z = y; // z is int, NOT int\&!}
2. \textbf{Keeping Qualifiers:} Use \passthrough{\lstinline!auto\&!} or
\passthrough{\lstinline!const auto\&!} to preserve them.
\passthrough{\lstinline!cpp     const int cx = 10;     auto copy = cx;       // int (const dropped)     const auto\& ref = cx; // const int\&!}

\hypertarget{decltype-inspecting-types}{%
\subsubsection{\texorpdfstring{1.2 \texttt{decltype}: Inspecting
Types}{1.2 decltype: Inspecting Types}}\label{decltype-inspecting-types}}

Unlike \passthrough{\lstinline!auto!},
\passthrough{\lstinline!decltype!} gives the \emph{exact} declared type
of an expression, including references and const.

\begin{lstlisting}[language={C++}]
int x = 0;
decltype(x) y = 5;      // int
decltype((x)) z = y;    // int& (because (x) is an lvalue expression)
\end{lstlisting}

\textbf{Use Case: Trailing Return Types} Allows return types to depend
on parameter types.

\begin{lstlisting}[language={C++}]
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}
\end{lstlisting}

\hypertarget{nullptr-the-null-pointer-literal}{%
\subsubsection{\texorpdfstring{1.3 \texttt{nullptr}: The Null Pointer
Literal}{1.3 nullptr: The Null Pointer Literal}}\label{nullptr-the-null-pointer-literal}}

Replaces \passthrough{\lstinline!NULL!} and \passthrough{\lstinline!0!}.
Type-safe and unambiguous.

\begin{lstlisting}[language={C++}]
void f(int);
void f(char*);

f(0);       // Calls f(int) -> Ambiguity resolved!
f(NULL);    // Implementation-defined (often f(int))
f(nullptr); // Calls f(char*)
\end{lstlisting}

\hypertarget{initialization-uniformity}{%

\hypertarget{uniform-initialization-brace-initialization}{%
\subsubsection{2.1 Uniform Initialization (Brace

Consistent syntax for initializing everything.

\begin{lstlisting}[language={C++}]
int x{5};               // Direct initialization
int y = {5};            // Copy list initialization
std::vector<int> v{1, 2, 3};
std::map<int, std::string> m{{1, "a"}, {2, "b"}};
\end{lstlisting}

\textbf{Narrowing Prevention:}

\begin{lstlisting}[language={C++}]
int x = 3.14;  // Compiles (warning), x becomes 3
// int y{3.14}; // ERROR: Narrowing conversion not allowed
\end{lstlisting}

\hypertarget{stdinitializer_list}{%
\subsubsection{\texorpdfstring{2.2
\texttt{std::initializer\_list}}{2.2 std::initializer\_list}}\label{stdinitializer_list}}

Allows objects to accept a list of elements (used in constructors of
containers).

\begin{lstlisting}[language={C++}]
#include <initializer_list>

class MyVector {
public:
    MyVector(std::initializer_list<int> list) {
        for (int x : list) {
            // ...
        }
    }
};
\end{lstlisting}

\hypertarget{control-flow-iteration}{%
\subsection{3. Control Flow \& Iteration}\label{control-flow-iteration}}

\hypertarget{range-based-for-loops}{%
\subsubsection{3.1 Range-Based For Loops}\label{range-based-for-loops}}

Syntactic sugar for iterating over arrays and containers.

\begin{lstlisting}[language={C++}]
std::vector<int> v = {1, 2, 3};

// By Value (Copy)
for (int x : v) { /* ... */ }

// By Reference (Modify)
for (auto& x : v) { x *= 2; }

// By Const Reference (Read-only, avoids copy)
for (const auto& x : v) { /* ... */ }
\end{lstlisting}

Works on anything with \passthrough{\lstinline!begin()!} and
\passthrough{\lstinline!end()!} iterators (or arrays).

\hypertarget{class-features}{%
\subsection{4. Class Features}\label{class-features}}

\hypertarget{explicit-overrides-override-final}{%
\subsubsection{\texorpdfstring{4.1 Explicit Overrides
(\texttt{override},
\texttt{final})}{4.1 Explicit Overrides (override, final)}}\label{explicit-overrides-override-final}}

Compiler-checked inheritance safety.

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline!override!}: Ensures you are actually
  overriding a base virtual function.
\item
  \passthrough{\lstinline!final!}: Prevents further overriding or
  inheritance.
\end{itemize}

\begin{lstlisting}[language={C++}]
class Base {
    virtual void foo(int);
};

class Derived : public Base {
    void foo(int) override;   // OK
    // void foo(float) override; // Error: signature mismatch
};

class Last final : public Base { // Cannot be inherited from
    void foo(int) final;         // Cannot be overridden
};
\end{lstlisting}

\hypertarget{defaulted-and-deleted-functions}{%
\subsubsection{4.2 Defaulted and Deleted
Functions}\label{defaulted-and-deleted-functions}}

Control compiler-generated functions.

\begin{lstlisting}[language={C++}]
class Widget {
public:
    Widget() = default; // Force generation of default constructor

    // Disable copying
    Widget(const Widget&) = delete;
    Widget& operator=(const Widget&) = delete;
};
\end{lstlisting}

\hypertarget{strongly-typed-enums-enum-class}{%
\subsubsection{\texorpdfstring{4.3 Strongly Typed Enums
(\texttt{enum\ class})}{4.3 Strongly Typed Enums (enum class)}}\label{strongly-typed-enums-enum-class}}

Scoped, strongly typed, and safe.

\begin{lstlisting}[language={C++}]
enum class Color : char { Red, Green, Blue }; // Underlying type char

Color c = Color::Red;
// int i = c; // Error: No implicit conversion
\end{lstlisting}

\hypertarget{delegating-constructors}{%
\subsubsection{4.4 Delegating
Constructors}\label{delegating-constructors}}

One constructor calls another.

\begin{lstlisting}[language={C++}]
class Box {
    int w, h;
public:
    Box(int width, int height) : w(width), h(height) {}
    Box() : Box(1, 1) {} // Delegate
};
\end{lstlisting}

\hypertarget{constexpr-c11-version}{%
\subsection{\texorpdfstring{5. \texttt{constexpr} (C++11
Version)}{5. constexpr (C++11 Version)}}\label{constexpr-c11-version}}

Compile-time constants and functions. In C++11,
\passthrough{\lstinline!constexpr!} functions must contain a
\emph{single return statement}.

\begin{lstlisting}[language={C++}]
constexpr int square(int x) {
    return x * x;
}

int array[square(5)]; // Valid: array size 25 determined at compile time
\end{lstlisting}

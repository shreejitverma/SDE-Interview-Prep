\hypertarget{stdexpected}{%
\subsection{\texorpdfstring{1.
\texttt{std::expected}}{1. std::expected}}\label{stdexpected}}

The standard way to return values or errors, replacing integer error
codes and exceptions in high-performance paths.

\hypertarget{basics}{%
\subsubsection{1.1 Basics}\label{basics}}

\begin{lstlisting}[language={C++}]
#include <expected>
#include <string>

enum class Error { InvalidInput, ConnectionFailed };

std::expected<int, Error> parse_int(std::string_view input) {
    if (input.empty()) return std::unexpected(Error::InvalidInput);
    return std::stoi(std::string(input));
}

int main() {
    auto result = parse_int("42");

    if (result) {
        std::cout << "Value: " << *result;
    } else {
        std::cout << "Error: " << (int)result.error();
    }
}
\end{lstlisting}

\hypertarget{monadic-chain}{%
\subsubsection{1.2 Monadic Chain}\label{monadic-chain}}

\passthrough{\lstinline!and\_then!},
\passthrough{\lstinline!transform!}, \passthrough{\lstinline!or\_else!}.

\begin{lstlisting}[language={C++}]
auto process = parse_int("42")
    .and_then([](int i) { return parse_int("10"); }) // Chain potentially failing op
    .transform([](int i) { return i * 2; })          // Transform value on success
    .or_else([](Error e) { return std::expected<int, Error>(0); }); // Handle error
\end{lstlisting}

\hypertarget{monadic-operations-for-stdoptional}{%
\subsection{\texorpdfstring{2. Monadic Operations for
\texttt{std::optional}}{2. Monadic Operations for std::optional}}\label{monadic-operations-for-stdoptional}}

C++23 adds monadic methods to \passthrough{\lstinline!std::optional!}
(C++17).

\begin{lstlisting}[language={C++}]
std::optional<int> get_id();
std::optional<std::string> get_name(int id);

auto name = get_id()
    .and_then(get_name)
    .value_or("Unknown");
\end{lstlisting}

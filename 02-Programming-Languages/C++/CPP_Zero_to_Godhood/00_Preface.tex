\hypertarget{about-the-author}{%
\subsection{About the Author}\label{about-the-author}}

Shreejit Verma is a dedicated software engineer and quantitative
developer with a passion for high-performance systems. With deep
expertise in C++, distributed systems, and algorithmic trading, this
book distills years of ``in the trenches'' experience into a single,
comprehensive volume. The goal is simple: to provide the resource I wish
I had when I starteda path that doesn't just teach syntax, but teaches
\textbf{architecture, performance, and hardware sympathy}.

\hypertarget{book-purpose-scope}{%
\subsection{Book Purpose \& Scope}\label{book-purpose-scope}}

This book is not just a language reference; it is a \textbf{career
accelerator}. It aims to bridge the gap between academic C++ (often
stuck in 1998) and the high-frequency trading/low-latency engineering
standards of 2026.

\textbf{We cover:} * \textbf{Legacy to Modern}: From
\passthrough{\lstinline!void*!} and \passthrough{\lstinline!malloc!} to
\passthrough{\lstinline!std::unique\_ptr!} and
\passthrough{\lstinline!std::pmr!}. * \textbf{Standards Evolution}: A
strict chronological progression from C++98 through C++23, with a
preview of C++26. * \textbf{Systems Programming}: Memory models,
atomics, networking, and compiler internals. * \textbf{Optimization}:
SIMD, cache locality, branch prediction, and lock-free data structures.

\hypertarget{target-audience}{%
\subsection{Target Audience}\label{target-audience}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{The Student}: Start at \textbf{Chapter 1}. Do not skip the
  ``Deep Dive'' sections; they lay the groundwork for understanding
  \emph{why} things crash.
\item
  \textbf{The Professional}: Use \textbf{Chapters 4-8} to update your
  stack to Modern C++.
\item
  \textbf{The Specialist}: Jump to \textbf{Part 17 (Low Latency)} or
  \textbf{Part 24 (Architecture)} for domain-specific mastery.
\end{enumerate}

\hypertarget{structure-of-the-book}{%
\subsection{Structure of the Book}\label{structure-of-the-book}}

The book is divided into \textbf{33 Chapters} (formerly ``Parts'')
organized into \textbf{5 Phases}:

\begin{itemize}
\tightlist
\item
  \textbf{Phase I: The Foundation (Chapters 1-3.5)}

  \begin{itemize}
  \tightlist
  \item
    Core syntax, OOP mechanics, and the ``Classic'' STL.
  \item
    \emph{Goal}: Write correct, compiling C++98 code.
  \end{itemize}
\item
  \textbf{Phase II: The Modern Renaissance (Chapters 4-6)}

  \begin{itemize}
  \tightlist
  \item
    C++11, C++14, and C++17. Move semantics, Lambdas, Smart Pointers.
  \item
    \emph{Goal}: Write safe, expressive, and efficient code.
  \end{itemize}
\item
  \textbf{Phase III: The Conceptual Revolution (Chapters 7-8)}

  \begin{itemize}
  \tightlist
  \item
    C++20/23. Concepts, Ranges, Coroutines, Modules.
  \item
    \emph{Goal}: Write generic, composable, and modular libraries.
  \end{itemize}
\item
  \textbf{Phase IV: Systems \& Architecture (Chapters 9-16)}

  \begin{itemize}
  \tightlist
  \item
    Metaprogramming, Memory Models, Distributed Systems.
  \item
    \emph{Goal}: Design scalable systems that span threads and machines.
  \end{itemize}
\item
  \textbf{Phase V: Godhood (Chapters 17-33)}

  \begin{itemize}
  \tightlist
  \item
    Hardware Sympathy, SIMD, Custom Allocators, Compiler Construction.
  \item
    \emph{Goal}: Squeeze every nanosecond out of the CPU.
  \end{itemize}
\end{itemize}

\hypertarget{conventions-style-guide}{%
\subsection{Conventions \& Style Guide}\label{conventions-style-guide}}

To ensure clarity, this book follows strict conventions:

\begin{itemize}
\tightlist
\item
  \textbf{Code Standards}: All code examples use
  \passthrough{\lstinline!Allman!} or \passthrough{\lstinline!K\&R!}
  brace styles and \passthrough{\lstinline!snake\_case!} for variables,
  consistent with the C++ Standard Library.
\item
  \textbf{Terminology}:

  \begin{itemize}
  \tightlist
  \item
    \textbf{UB}: Undefined Behavior (The compiler can do anything).
  \item
    \textbf{Ill-formed}: The code will not compile.
  \item
    \textbf{ODR}: One Definition Rule.
  \end{itemize}
\item
  \textbf{Measurable Outcomes}: Each major section concludes with a
  ``Skill Check'' or ``Implementation Task'' to verify mastery.
\end{itemize}

\hypertarget{constexpr-evolution}{%
\subsection{\texorpdfstring{1. \texttt{constexpr}
Evolution}{1. constexpr Evolution}}\label{constexpr-evolution}}

\begin{itemize}
\tightlist
\item
  \textbf{C++11:} Single return statement. Very restricted.
\item
  \textbf{C++14:} Loops, local variables, multiple returns allowed.
\item
  \textbf{C++17:} \passthrough{\lstinline!if constexpr!}, lambdas can be
  constexpr.
\item
  \textbf{C++20:} Virtual functions,
  \passthrough{\lstinline!try-catch!}, dynamic allocation
  (\passthrough{\lstinline!std::vector!},
  \passthrough{\lstinline!std::string!}) allowed in constexpr context
  (transient allocation).
\end{itemize}

\hypertarget{consteval-c20}{%
\subsection{\texorpdfstring{2. \texttt{consteval}
(C++20)}{2. consteval (C++20)}}\label{consteval-c20}}

Forces immediate execution. If it can't run at compile time, it's an
error.

\begin{lstlisting}[language={C++}]
consteval int square(int n) { return n * n; }

int x = square(5); // OK
int y = 10;
// int z = square(y); // Error: y is not a constant expression
\end{lstlisting}

\hypertarget{stdintegral_constant}{%
\subsection{\texorpdfstring{4.
\texttt{std::integral\_constant}}{4. std::integral\_constant}}\label{stdintegral_constant}}

Wraps a compile-time value as a type.

\begin{lstlisting}[language={C++}]
using Two = std::integral_constant<int, 2>;
using Four = std::integral_constant<int, 4>;

static_assert(Two::value + Two::value == Four::value);
\end{lstlisting}

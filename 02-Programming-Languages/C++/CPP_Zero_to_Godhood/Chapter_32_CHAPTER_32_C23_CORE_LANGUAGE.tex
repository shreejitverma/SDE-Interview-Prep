\hypertarget{deducing-this-explicit-object-parameter}{%
\subsection{\texorpdfstring{1. Deducing \texttt{this} (Explicit Object
Parameter)}{1. Deducing this (Explicit Object Parameter)}}\label{deducing-this-explicit-object-parameter}}

This is one of the most significant changes in C++23. It allows member
functions to deduce the value category (\passthrough{\lstinline!const!},
\passthrough{\lstinline!\&!}, \passthrough{\lstinline!\&\&!}) of the
object they are called on, without writing 4+ overloads.

\hypertarget{the-problem-c20-and-older}{%
\subsubsection{1.1 The Problem (C++20 and
older)}\label{the-problem-c20-and-older}}

To handle lvalues, const lvalues, rvalues, and const rvalues, you needed
overloads:

\begin{lstlisting}[language={C++}]
struct Widget {
    void process() &;       // lvalue
    void process() const&;  // const lvalue
    void process() &&;      // rvalue
    void process() const&&; // const rvalue
};
\end{lstlisting}

\hypertarget{the-solution}{%
\subsubsection{1.2 The Solution}\label{the-solution}}

Pass \passthrough{\lstinline!this!} as an explicit argument.

\begin{lstlisting}[language={C++}]
struct Widget {
    // 'self' deduces the type of the object (e.g., Widget&, const Widget&, Widget&&)
    template <typename Self>
    void process(this Self&& self) {
        // Forward self to another function
        handle(std::forward<Self>(self));
    }
};
\end{lstlisting}

\hypertarget{recursive-lambdas}{%
\subsubsection{1.3 Recursive Lambdas}\label{recursive-lambdas}}

Deducing \passthrough{\lstinline!this!} allows lambdas to be recursive
without \passthrough{\lstinline!std::function!} or hacks.

\begin{lstlisting}[language={C++}]
auto fib = [](this auto&& self, int n) {
    if (n <= 1) return n;
    return self(n - 1) + self(n - 2);
};

int result = fib(10); // 55
\end{lstlisting}

\hypertarget{if-consteval}{%
\subsection{\texorpdfstring{2.
\texttt{if\ consteval}}{2. if consteval}}\label{if-consteval}}

A safer version of
\passthrough{\lstinline!if (std::is\_constant\_evaluated())!}.

\begin{lstlisting}[language={C++}]
consteval int compile_time_algo(int n) { return n * n; }
int runtime_algo(int n) { return n * n; }

constexpr int heavy_math(int n) {
    if consteval {
        return compile_time_algo(n); // Executed ONLY at compile time
    } else {
        return runtime_algo(n);      // Executed at runtime
    }
}
\end{lstlisting}

\hypertarget{multidimensional-subscript-operator-operator}{%
\subsection{\texorpdfstring{3. Multidimensional Subscript Operator
(\texttt{operator{[}{]}})}{3. Multidimensional Subscript Operator (operator{[}{]})}}\label{multidimensional-subscript-operator-operator}}

C++23 finally allows multiple arguments in \passthrough{\lstinline![]!}.

\begin{lstlisting}[language={C++}]
struct Matrix {
    std::vector<double> data;
    size_t cols;

    double& operator[](size_t r, size_t c) {
        return data[r * cols + c];
    }
};

Matrix m;
m[1, 2] = 3.14; // Clean syntax!
\end{lstlisting}

\hypertarget{autox-decay-copy}{%
\subsection{\texorpdfstring{4. \texttt{auto(x)}: Decay
Copy}{4. auto(x): Decay Copy}}\label{autox-decay-copy}}

Explicitly create a prvalue copy of an lvalue. Useful in generic code to
prevent accidental referencing.

\begin{lstlisting}[language={C++}]
void process(const auto& x) {
    auto copy = auto(x); // Explicit decay-copy
    // ...
}
\end{lstlisting}

\hypertarget{literal-suffixes-for-size_t}{%
\subsection{\texorpdfstring{5. Literal Suffixes for
\texttt{size\_t}}{5. Literal Suffixes for size\_t}}\label{literal-suffixes-for-size_t}}

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline!uz!} or \passthrough{\lstinline!z!} for
  \passthrough{\lstinline!size\_t!} (unsigned equivalent of
  \passthrough{\lstinline!ptrdiff\_t!}).
\item
  \passthrough{\lstinline!z!} for \passthrough{\lstinline!ptrdiff\_t!}
  (signed).
\end{itemize}

\begin{lstlisting}[language={C++}]
auto s = 100uz; // std::size_t
auto p = 100z;  // std::ptrdiff_t
\end{lstlisting}

\section{CHAPTER 26: C20 CONCEPTS}\label{chapter-26-c20-concepts}}

\hypertarget{c20-concepts-constraints}{%
\section{C++20 CONCEPTS \& CONSTRAINTS}\label{c20-concepts-constraints}}

Concepts are the first of the ``Four Great Pillars'' of C++20. They
revolutionize template programming by providing a formal way to specify
requirements on template arguments.

\hypertarget{the-core-mechanics}{%
\subsubsection{1. The Core Mechanics}\label{the-core-mechanics}}

\begin{itemize}
\tightlist
\item
  \textbf{Concepts}: Compile-time constraints on template parameters,
  replacing cryptic SFINAE errors with clear diagnostics.
  \passthrough{\lstinline!cpp     template<typename T>     concept Addable = requires(T a, T b) \{ a + b; \};!}
\item
  \textbf{Requires expressions}: Inline constraint blocks that test the
  validity of expressions, types, or compound requirements.
  \passthrough{\lstinline!cpp     template<typename T>     concept Advanced = requires(T x) \{         x++;                        // Simple requirement         typename T::value\_type;      // Type requirement         \{*x\} -> std::same\_as<int>;   // Compound requirement     \};!}
\item
  \textbf{Requires clauses}: Attaches a constraint to a template or
  function declaration using the \passthrough{\lstinline!requires!}
  keyword.
  \passthrough{\lstinline!cpp     template<typename T>     requires Addable<T>     void f(T a) \{ /* ... */ \}!}
\item
  \textbf{Constrained auto}: \passthrough{\lstinline!auto!} parameters
  in functions and variables can be constrained with a concept.
  \passthrough{\lstinline!cpp     void f(std::integral auto x) \{ /* x must be an integer type */ \}!}
\item
  \textbf{Partial ordering by constraints}: Among multiple viable
  overloads, the most-constrained one is selected automatically.
  \passthrough{\lstinline!cpp     void f(std::integral auto);      void f(std::signed\_integral auto);      f(1); // picks signed\_integral (more specific)!}
\end{itemize}

\hypertarget{standard-concepts}{%
\subsubsection{2. Standard Concepts}\label{standard-concepts}}

The \passthrough{\lstinline!<concepts>!} header provides a massive
library of pre-defined constraints: * \textbf{Core}:
\passthrough{\lstinline!std::derived\_from!},
\passthrough{\lstinline!std::convertible\_to!},
\passthrough{\lstinline!std::same\_as!},
\passthrough{\lstinline!std::integral!},
\passthrough{\lstinline!std::floating\_point!}. * \textbf{Object}:
\passthrough{\lstinline!std::movable!},
\passthrough{\lstinline!std::copyable!},
\passthrough{\lstinline!std::semiregular!},
\passthrough{\lstinline!std::regular!}. * \textbf{Callable}:
\passthrough{\lstinline!std::invocable!},
\passthrough{\lstinline!std::predicate!}.

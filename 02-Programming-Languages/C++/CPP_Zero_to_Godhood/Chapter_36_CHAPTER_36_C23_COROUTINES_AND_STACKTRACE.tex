\hypertarget{stdgenerator}{%
\subsubsection{\texorpdfstring{1.
\texttt{std::generator}}{1. std::generator}}\label{stdgenerator}}

C++20 provided the core language support for coroutines, but no standard
library types. C++23 introduces
\passthrough{\lstinline!std::generator!}, a ready-to-use return type for
synchronous coroutine generators that works seamlessly with Ranges.

\begin{lstlisting}[language={C++}]
#include <generator>

std::generator<int> fibonacci() {
    int a = 0, b = 1;
    while (true) {
        co_yield a;
        auto next = a + b;
        a = b;
        b = next;
    }
}

// Seamless integration with views
auto first_10 = fibonacci() | std::views::take(10);
\end{lstlisting}

\hypertarget{stdstacktrace}{%
\subsubsection{\texorpdfstring{2.
\texttt{std::stacktrace}}{2. std::stacktrace}}\label{stdstacktrace}}

Native support for capturing and printing call stacks, revolutionizing
C++ debugging and error logging.

\begin{lstlisting}[language={C++}]
#include <stacktrace>
#include <print>

void crash_handler() {
    std::println("Crash! Stacktrace:
{}", std::stacktrace::current());
}
\end{lstlisting}

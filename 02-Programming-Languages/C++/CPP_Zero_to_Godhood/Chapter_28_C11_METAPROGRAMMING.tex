C++11 made Template Metaprogramming (TMP) usable by mere mortals.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{variadic-templates}{%
\section{1. VARIADIC TEMPLATES}\label{variadic-templates}}

Templates that accept an arbitrary number of arguments.

\begin{lstlisting}[language={C++}]
template<typename T>
T sum(T t) { return t; }

template<typename T, typename... Args>
T sum(T t, Args... args) {
    return t + sum(args...);
}

// sum(1, 2, 3, 4) -> 10
\end{lstlisting}

\hypertarget{type-traits}{%
\section{2. TYPE TRAITS}\label{type-traits}}

The \passthrough{\lstinline!<type\_traits>!} header allows compile-time
inspection of types.

\begin{lstlisting}[language={C++}]
#include <type_traits>

static_assert(std::is_integral<int>::value, "Int must be integral");
static_assert(std::is_pointer<int*>::value, "Must be pointer");
\end{lstlisting}

Used heavily with \textbf{SFINAE}
(\passthrough{\lstinline!std::enable\_if!}) to restrict templates.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{constexpr-introduction}{%
\section{3. CONSTEXPR (INTRODUCTION)}\label{constexpr-introduction}}

\passthrough{\lstinline!constexpr!} functions can be evaluated at
compile-time.

\begin{lstlisting}[language={C++}]
constexpr int square(int x) { return x * x; }

int array[square(5)]; // Valid! Size 25 at compile time.
\end{lstlisting}

In C++11, \passthrough{\lstinline!constexpr!} functions were very
limited (single return statement). C++14 relaxed this.

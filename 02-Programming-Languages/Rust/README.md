# Rust

This folder collects the Rust toolchain notes, which live in [Developer Toolchain](../../18-Developer-Toolchain/README.md).
Rust language notes, the counterpart of the C++ and Python books, are a separate later project.

- [Rust debugging](../../18-Developer-Toolchain/03-Debugging/Rust/README.md): rust-gdb and rust-lldb, panics, Miri, sanitizers, loom, and async debugging.
- [Rust profiling](../../18-Developer-Toolchain/05-Profiling/Rust/README.md): samply, flamegraphs, Criterion and Divan, and compile-time profiling.
- [Rust packaging](../../18-Developer-Toolchain/07-Packaging-and-Release/Rust/README.md): the Cargo model, SemVer checks, publishing, and shipping Rust inside Python wheels.

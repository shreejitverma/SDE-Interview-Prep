\hypertarget{the-hierarchy-of-loggers}{%
\subsection{97.1 The Hierarchy of
Loggers}\label{the-hierarchy-of-loggers}}

Logging in Python uses a tree-based hierarchy. * \textbf{Propagation}:
Child loggers pass messages up to their parents unless
\passthrough{\lstinline!propagate!} is False. * \textbf{Handlers}:
Direct the log messages to different destinations (Console, File,
Network, Email).

\hypertarget{the-logging.config-dictionary}{%
\subsection{\texorpdfstring{97.2 The \texttt{logging.config}
Dictionary}{97.2 The logging.config Dictionary}}\label{the-logging.config-dictionary}}

The most robust way to configure logging is via a dictionary (often
loaded from JSON or YAML), allowing for a clean separation between code
and configuration.

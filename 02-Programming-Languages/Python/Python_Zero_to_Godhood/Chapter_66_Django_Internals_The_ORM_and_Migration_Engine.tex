\chapter{Django Internals: The ORM and Migration
Engine}\label{django-internals-the-orm-and-migration-engine}}

Django is the ``batteries-included'' web framework. * \textbf{The ORM}:
Translates Python class definitions into SQL. It uses a complex
tree-based query generator to handle joins and filters. *
\textbf{Migrations}: Uses the \passthrough{\lstinline!ast!} module to
analyze changes in models and generate the minimal SQL required to
update the database schema.

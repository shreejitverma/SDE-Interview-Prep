\chapter{SciPy: Optimization and Linear Algebra
Backends}\label{scipy-optimization-and-linear-algebra-backends}}

SciPy builds on NumPy, providing interfaces to legacy but highly
optimized libraries like \textbf{LAPACK} and \textbf{BLAS}. *
\textbf{Sparse Matrices}: Storing large matrices with many zeros using
CSR (Compressed Sparse Row) or CSC (Compressed Sparse Column) formats to
save memory. * \textbf{Optimization}: Implementations of algorithms like
BFGS and Nelder-Mead in C/Fortran.

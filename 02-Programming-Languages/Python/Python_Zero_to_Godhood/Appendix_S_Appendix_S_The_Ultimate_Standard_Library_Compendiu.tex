\hypertarget{appendix-s-the-ultimate-standard-library-compendium-a-z}{%
\chapter{Appendix S: The Ultimate Standard Library Compendium
(A-Z)}\label{appendix-s-the-ultimate-standard-library-compendium-a-z}}

This appendix provides a comprehensive technical overview of every
module in the Python 3.13 Standard Library, serving as the final
``Sovereign Reference'' for the language.

\hypertarget{s.1-a-b}{%
\subsection{S.1 {[}A-B{]}}\label{s.1-a-b}}

\begin{itemize}
\tightlist
\item
  \textbf{\passthrough{\lstinline!abc!}}: Abstract Base Classes. Used to
  define interfaces and perform virtual subclassing (Chapter 64).
\item
  \textbf{\passthrough{\lstinline!aifc!}}: (Removed in 3.13)
  Historically used for AIFF audio files.
\item
  \textbf{\passthrough{\lstinline!argparse!}}: Declarative command-line
  argument parsing with support for subcommands and type conversion
  (Chapter 58).
\item
  \textbf{\passthrough{\lstinline!array!}}: Space-efficient storage of
  basic C-style data types (integers, floats) in a contiguous memory
  block.
\item
  \textbf{\passthrough{\lstinline!ast!}}: Tools to parse and manipulate
  the Abstract Syntax Tree of Python source code (Chapter 31).
\item
  \textbf{\passthrough{\lstinline!asyncio!}}: The foundational framework
  for concurrent, non-blocking I/O using the event loop and coroutines
  (Chapter 27).
\item
  \textbf{\passthrough{\lstinline!atexit!}}: Registry for functions to
  be called upon normal interpreter termination.
\item
  \textbf{\passthrough{\lstinline!audioop!}}: (Removed in 3.13)
  Low-level manipulation of raw audio data.
\item
  \textbf{\passthrough{\lstinline!base64!}}: RFC 4648 encoding/decoding,
  often SIMD-accelerated in the C backend (Chapter 44).
\item
  \textbf{\passthrough{\lstinline!bdb!}}: Debugger framework providing
  the foundation for \passthrough{\lstinline!pdb!}.
\item
  \textbf{\passthrough{\lstinline!binascii!}}: Low-level conversions
  between binary and various ASCII-encoded binary representations.
\item
  \textbf{\passthrough{\lstinline!bisect!}}: Optimized binary search
  algorithms for sorted lists (Chapter 33).
\item
  \textbf{\passthrough{\lstinline!builtins!}}: The core namespace
  containing all ``default'' Python functions and types (Appendix L).
\item
  \textbf{\passthrough{\lstinline!bz2!}}: Interface for the bzip2
  compression library using the Burrows-Wheeler algorithm (Chapter 49).
\end{itemize}

\hypertarget{s.2-c-d}{%
\subsection{S.2 {[}C-D{]}}\label{s.2-c-d}}

\begin{itemize}
\tightlist
\item
  \textbf{\passthrough{\lstinline!calendar!}}: Functions for date
  calculations based on the Proleptic Gregorian Calendar.
\item
  \textbf{\passthrough{\lstinline!cgi!}}: (Removed in 3.13) Common
  Gateway Interface support for web servers.
\item
  \textbf{\passthrough{\lstinline!cgitb!}}: (Removed in 3.13) Traceback
  manager for CGI scripts.
\item
  \textbf{\passthrough{\lstinline!chunk!}}: (Removed in 3.13) Read IFF
  chunked data.
\item
  \textbf{\passthrough{\lstinline!cmath!}}: Mathematical functions for
  complex numbers (Appendix A).
\item
  \textbf{\passthrough{\lstinline!cmd!}}: Framework for building
  interactive line-oriented command interpreters (Chapter 58).
\item
  \textbf{\passthrough{\lstinline!code!}}: Facilities to implement
  custom Python REPLs.
\item
  \textbf{\passthrough{\lstinline!codecs!}}: Registry and base classes
  for character encodings and stream transformations.
\item
  \textbf{\passthrough{\lstinline!codeop!}}: Internal helper for
  compiling partially-complete Python code (used in REPLs).
\item
  \textbf{\passthrough{\lstinline!collections!}}: High-performance
  container alternatives to \passthrough{\lstinline!list!} and
  \passthrough{\lstinline!dict!} (Chapter 33).
\item
  \textbf{\passthrough{\lstinline!colorsys!}}: Conversions between RGB
  and other color systems (YIQ, HLS, HSV).
\item
  \textbf{\passthrough{\lstinline!compileall!}}: Byte-compiles all
  Python source files in a directory tree.
\item
  \textbf{\passthrough{\lstinline!configparser!}}: Configuration file
  parser for INI-style files (Chapter 51).
\item
  \textbf{\passthrough{\lstinline!contextlib!}}: Utilities for
  \passthrough{\lstinline!with!}-statement context managers (Chapter
  65).
\item
  \textbf{\passthrough{\lstinline!contextvars!}}: Support for
  context-local variables, critical for
  \passthrough{\lstinline!asyncio!} state management.
\item
  \textbf{\passthrough{\lstinline!copy!}}: Shallow and deep copy
  operations for arbitrary Python objects.
\item
  \textbf{\passthrough{\lstinline!copyreg!}}: Registration for custom
  \passthrough{\lstinline!pickle!} functions.
\item
  \textbf{\passthrough{\lstinline!crypt!}}: (Removed in 3.13) Interface
  to the POSIX \passthrough{\lstinline!crypt()!} function.
\item
  \textbf{\passthrough{\lstinline!csv!}}: C-accelerated parser for
  comma-separated value files with dialect support (Chapter 51).
\item
  \textbf{\passthrough{\lstinline!ctypes!}}: Foreign Function Interface
  (FFI) for calling functions in shared C libraries (Chapter 24).
\item
  \textbf{\passthrough{\lstinline!curses!}}: Terminal handling for
  character-cell displays (Unix only).
\item
  \textbf{\passthrough{\lstinline!dataclasses!}}: Boilerplate-reduction
  for classes primarily used to store data (Chapter 13).
\item
  \textbf{\passthrough{\lstinline!datetime!}}: Packed binary
  representation of dates and times with DST support (Chapter 46).
\item
  \textbf{\passthrough{\lstinline!dbm!}}: Generic interface to variants
  of the DBM database (ndbm, gdbm, bdb).
\item
  \textbf{\passthrough{\lstinline!decimal!}}: Arbitrary-precision
  decimal arithmetic based on the decNumber library (Chapter 35).
\item
  \textbf{\passthrough{\lstinline!difflib!}}: Helpers for computing and
  visualizing differences between sequences.
\item
  \textbf{\passthrough{\lstinline!dis!}}: The disassembler for Python
  bytecode (Chapter 62).
\item
  \textbf{\passthrough{\lstinline!doctest!}}: Tool for verifying code
  examples embedded in docstrings (Chapter 41).
\end{itemize}

\item
  \textbf{\passthrough{\lstinline!gzip!}}: Interface for files

  \textbf{\passthrough{\lstinline!hashlib!}}: Secure hash and message
  digest algorithms backed by OpenSSL (Chapter 45).
\item
  \textbf{\passthrough{\lstinline!heapq!}}: Min-priority queue

\item
  \textbf{\passthrough{\lstinline!hmac!}}: Keyed-Hashing for Message

\item
  \textbf{\passthrough{\lstinline!html!}}: Support for manipulating

\item
  \textbf{\passthrough{\lstinline!http!}}: Constants and state machines

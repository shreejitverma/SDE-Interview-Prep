\hypertarget{value-at-risk-var}{%
\subsection{88.1 Value at Risk (VaR)}\label{value-at-risk-var}}

Estimating the maximum loss at a given confidence level over a specific
time horizon. * \textbf{Historical Simulation}: Using historical data to
predict future risk. * \textbf{Parametric VaR}: Using the normal
distribution and covariance matrices.

\hypertarget{expected-shortfall-cvar}{%
\subsection{88.2 Expected Shortfall
(CVaR)}\label{expected-shortfall-cvar}}

Measuring the average loss in the ``tail'' beyond the VaR threshold.
This provides a more robust measure of extreme risk.

\hypertarget{advanced-formatting-the-mini-language}{%
\subsection{92.2 Advanced Formatting: The
Mini-Language}\label{advanced-formatting-the-mini-language}}

The string formatting mini-language (used in
\passthrough{\lstinline!f-strings!} and
\passthrough{\lstinline!.format()!}) allows for precise control. *
\textbf{Alignment}: \passthrough{\lstinline!:<10!} (left),
\passthrough{\lstinline!:>10!} (right), \passthrough{\lstinline!:\^10!}
(center). * \textbf{Number Formatting}: \passthrough{\lstinline!:0.2f!}
(float precision), \passthrough{\lstinline!:,!} (thousands separator),
\passthrough{\lstinline!:b!} (binary), \passthrough{\lstinline!:x!}
(hex). * \textbf{Sign Handling}: \passthrough{\lstinline!:+!} (always
show sign), \passthrough{\lstinline!:-!} (only for negative).

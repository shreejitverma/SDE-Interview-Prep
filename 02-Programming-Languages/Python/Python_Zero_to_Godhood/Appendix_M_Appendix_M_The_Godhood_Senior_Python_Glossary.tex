\chapter{Appendix M: The ``Godhood'' Senior Python
Glossary}\label{appendix-m-the-godhood-senior-python-glossary}}

\begin{itemize}
\tightlist
\item
  \textbf{Duck Typing}: ``If it walks like a duck and quacks like a
  duck, it's a duck.'' Focus on behavior rather than types.
\item
  \textbf{EAFP}: ``Easier to Ask Forgiveness than Permission.'' Use
  \passthrough{\lstinline!try...except!} instead of checking
  \passthrough{\lstinline!if!} conditions.
\item
  \textbf{LBYL}: ``Look Before You Leap.'' The opposite of EAFP;
  checking preconditions before execution.
\item
  \textbf{Monkey Patching}: Dynamically replacing attributes (functions,
  classes) at runtime.
\item
  \textbf{Namespace}: A mapping from names to objects.
\item
  \textbf{Pythonic}: Code that follows the idioms and philosophy of the
  Python community (PEP 20).
\item
  \textbf{Virtual Machine}: The software that executes Python bytecode
  (CPython).
\end{itemize}

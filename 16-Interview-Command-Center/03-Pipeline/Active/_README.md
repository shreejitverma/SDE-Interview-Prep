# 🎯 Active Pipeline — Structured Interview Directory Standards

> Every company application and interview has its own dedicated folder to keep preparation structured, comprehensive, and modular.

---

## 📁 Standard Directory Structure

```
Active/
└── [Company-Name]/
    ├── 01-[Track-or-Role-Name]-[Interviewer]/
    │   ├── [Company]-[Role]-Interview-Tracker.md   # Primary Dataview-tracked interview note
    │   ├── [Domain]-Study-Guide.md                 # Deep technical / domain study material
    │   ├── Technical-Interview-Prep.md             # Code patterns, architecture, system design
    │   └── Manager-Round-Prep.md                   # Manager profile, Q&A scenarios, reverse questions
    ├── 02-[Alternative-Track]/                    # If multiple roles/managers at the company
    │   └── ...
    └── Shared-[Company]-Prep/
        ├── [Company]-Behavioral-STAR-Bank.md       # Tailored STAR stories for company values
        └── [Company]-Company-Brief.md              # Compensation, recruiter, VMS, logistics
```

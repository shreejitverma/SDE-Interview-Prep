# AI Engineer Study Plan - 10-Week Sprint

## Week 1-2: ML Fundamentals Refresh
- [ ] Linear/logistic regression, gradient descent, regularization (L1/L2)
- [ ] Decision trees, random forests, boosting (XGBoost, LightGBM)
- [ ] SVMs, k-NN, clustering (K-means, DBSCAN)
- [ ] Evaluation: precision/recall/F1, ROC-AUC, confusion matrix
- [ ] Cross-validation, bias-variance tradeoff, overfitting/underfitting
- [ ] **Daily:** Implement 1 algorithm from scratch in Python

## Week 3-4: Deep Learning & Transformers
- [ ] Neural networks: forward/backward prop, activation functions, batch norm
- [ ] CNNs: convolution, pooling, architectures (ResNet, EfficientNet)
- [ ] RNNs/LSTMs: vanishing gradients, sequence modeling
- [ ] **Transformers:** Self-attention, multi-head attention, positional encoding
- [ ] GPT architecture, BERT, encoder vs decoder vs encoder-decoder
- [ ] Training: learning rate schedules, Adam/AdamW, gradient clipping, mixed precision
- [ ] **Resource:** [[13-Agentic-AI/Agentic_AI_Zero_to_Godhood]]

## Week 5-6: LLMs, RAG & Agentic Systems
- [ ] LLM internals: tokenization, KV cache, rotary embeddings, flash attention
- [ ] Scaling laws (Chinchilla), emergent abilities, in-context learning
- [ ] Fine-tuning: LoRA, QLoRA, PEFT, full fine-tuning trade-offs
- [ ] RLHF: reward modeling, PPO, DPO, constitutional AI
- [ ] RAG: retrieval strategies, chunking, re-ranking, hybrid search
- [ ] Agentic AI: tool use, planning, multi-agent, function calling
- [ ] **Resource:** [[13-Agentic-AI/Agentic_AI_Zero_to_Godhood]]

## Week 7-8: ML System Design
- [ ] ML system design framework (see Common-Patterns)
- [ ] Design: recommendation system (YouTube, Netflix)
- [ ] Design: search ranking system (Google, Bing)
- [ ] Design: content moderation system (large-scale)
- [ ] Design: LLM serving infrastructure (multi-tenant, low latency)
- [ ] Design: training pipeline for billion-parameter model
- [ ] Feature stores, experiment tracking, A/B testing for ML

## Week 9-10: Coding, Mocks & Company Prep
- [ ] DSA: 2-3 problems/day (LeetCode medium/hard)
- [ ] ML coding: implement attention, custom loss, data pipeline
- [ ] 3 full mock interviews (ML design + coding + theory)
- [ ] Company-specific: research recent papers, blog posts, products
- [ ] OpenAI/Anthropic: alignment awareness, safety considerations
- [ ] DeepMind: research paper discussion, mathematical depth

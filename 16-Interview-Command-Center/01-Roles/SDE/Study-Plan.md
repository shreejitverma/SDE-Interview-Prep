# 📋 SDE Study Plan — 8-Week Sprint

> Adjust timelines based on your interview dates. Focus on weak areas first.

---

## Week 1-2: DSA Foundations Blitz
- [ ] Arrays & Strings: Sliding window, two pointers, prefix sums (15 problems)
- [ ] Hash Maps: Design + application problems (10 problems)
- [ ] Linked Lists: Reversal patterns, fast/slow pointers (8 problems)
- [ ] Stacks & Queues: Monotonic stack, next greater element (8 problems)
- [ ] **Daily:** 3-4 LeetCode problems, timed (25 min each)
- [ ] **Resource:** [[03-Data-Structures-Algorithms/01-Topics]]

## Week 3-4: Trees, Graphs, & Advanced DSA
- [ ] Binary Trees: DFS/BFS, serialize/deserialize, LCA (12 problems)
- [ ] BST: Validation, iterators, floor/ceiling (8 problems)
- [ ] Graphs: BFS/DFS, topological sort, Union-Find, Dijkstra (15 problems)
- [ ] Dynamic Programming: 1D, 2D, knapsack, LIS, interval DP (20 problems)
- [ ] Backtracking: Permutations, combinations, N-Queens (8 problems)
- [ ] **Daily:** 3-4 problems + 1 hard problem attempt
- [ ] **Resource:** [[03-Data-Structures-Algorithms/04-Gold-Standard-Cpp-Patterns]]

## Week 5-6: System Design
- [ ] Fundamentals: CAP theorem, consistency models, load balancing, caching
- [ ] Case Studies: URL shortener, rate limiter, chat system, news feed
- [ ] Deep Dives: Database sharding, message queues, CDN design
- [ ] Low-Level Design: Parking lot, elevator, LRU cache implementation
- [ ] **Daily:** 1 system design practice (45 min) + 2 coding problems
- [ ] **Resource:** [[04-System-Design/00-Concepts]], [[04-System-Design/02-Case-Studies]]

## Week 7: Behavioral & Mock Interviews
- [ ] Polish 8-10 STAR stories → [[05-Behavioral/_Story-Index]]
- [ ] Map stories to company values (Amazon LPs, Google Googliness)
- [ ] Practice each story out loud (2 min max)
- [ ] 2 full mock interviews (coding + system design + behavioral)
- [ ] Review all retrospectives for pattern analysis
- [ ] **Daily:** 1-2 coding problems to stay sharp

## Week 8: Final Sprint & Company-Specific Prep
- [ ] Review weak areas identified in mock interviews
- [ ] Re-solve all problems that took >30 min
- [ ] Company-specific prep (research team, recent blog posts, products)
- [ ] Practice "Why [Company]?" answers for each target
- [ ] Light problem-solving to maintain confidence (2/day)
- [ ] **Sleep well. Trust your preparation.**

# 🔵 Meta — Core Values Behavioral Guide

> Meta behavioral interviews focus on their core values. Every answer should demonstrate one or more.

---

## Meta Core Values

| Value | What They Want | Story Mapping |
|-------|---------------|---------------|
| **Move Fast** | Speed of execution, bias for action, shipping | |
| **Be Bold** | Taking risks, thinking big, ambitious goals | |
| **Focus on Impact** | Prioritization, measurable outcomes, ROI thinking | |
| **Be Open** | Transparency, feedback culture, sharing information | |
| **Build Social Value** | Positive impact, responsible technology | |

## Tips
- Meta values SPEED above all — show you can ship quickly
- "Impact" is the magic word — quantify everything
- They appreciate candor and directness
- Less formal than Google — more startup energy
- E5+ must show cross-team influence

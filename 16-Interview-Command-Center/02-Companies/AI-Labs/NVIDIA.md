# NVIDIA
## 🏢 Overview
The GPU company powering AI. CUDA, TensorRT, cuDNN, DGX, H100/B200. ~$3T+ market cap. Every AI lab depends on NVIDIA hardware.

## 📋 Interview Process
- Coding + systems + GPU/CUDA knowledge
- For AI roles: deep learning + model optimization + GPU programming
- For systems roles: CUDA, driver development, low-level C++
- They test: parallel programming, GPU memory hierarchy, kernel optimization

### Tips
- CUDA knowledge is a strong differentiator
- Understand GPU memory hierarchy (global, shared, registers, L2)
- Know TensorRT, quantization, mixed precision
- Jensen Huang culture: "The more you learn, the more you earn"

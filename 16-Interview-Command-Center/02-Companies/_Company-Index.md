## 📊 All Companies

```dataview
TABLE WITHOUT ID
  file.link AS "Company",
  industry AS "Industry",
  target_roles AS "Target Roles",
  status AS "Status"
FROM "16-Interview-Command-Center/02-Companies"
WHERE file.name != "_Company-Index"
SORT industry ASC, file.name ASC
```

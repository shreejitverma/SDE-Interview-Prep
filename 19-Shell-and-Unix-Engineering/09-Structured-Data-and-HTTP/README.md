# Structured Data and HTTP

JSON, YAML, CSV, and HTTP APIs are the common case now, and line-oriented tools mishandle all of them.
These notes cover the structured tools that replace them and the signs that a pipeline should become a program.

Part of [Shell and Unix Engineering](../README.md).

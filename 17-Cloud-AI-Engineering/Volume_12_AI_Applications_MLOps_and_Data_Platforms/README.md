# Volume 12 - AI Applications, MLOps, and Data Platforms

Volume 12 - AI Applications, MLOps, and Data Platforms in the Cloud AI Engineering Zero to Godhood curriculum.

## Chapters

1. [Vector Databases and Similarity Search on Cloud](Chapter_01_Vector_Databases_and_Similarity_Search_on_Cloud.md) - OpenSearch, Vertex AI Vector Search, AlloyDB and Aurora pgvector, HNSW vs IVF indexing, and p99 query latency scaling.
2. [Enterprise Retrieval-Augmented Generation Architecture](Chapter_02_Enterprise_Retrieval_Augmented_Generation_Architecture.md) - Bedrock Knowledge Bases, Vertex AI Search, document ingestion chunking, sparse/dense hybrid search, and cross-encoder rerankers.
3. [Agent Runtimes and Cloud Execution Environments](Chapter_03_Agent_Runtimes_and_Cloud_Execution_Environments.md) - Bedrock Agents, Vertex AI Agent Builder, secure sandbox execution, tool integration, and state machine persistence.
4. [MLOps Pipelines: SageMaker vs Vertex AI Pipelines](Chapter_04_MLOps_Pipelines_SageMaker_vs_Vertex_AI.md) - Directed acyclic graph workflow engines, Kubeflow lineage tracking, artifact metadata repositories, and reproducible step caching.

6. [Model Evaluation, Monitoring, and Drift Detection](Chapter_06_Model_Evaluation_Monitoring_and_Drift_Detection.md) - Offline benchmark pipelines, online prediction sampling, feature drift and concept drift calculation, and LLM-as-a-judge evaluation pipelines.

8. [Cloud Security for AI Systems: Attacks and Defenses](Chapter_08_Cloud_Security_for_AI_Systems_Attacks_and_Defenses.md) - Prompt injection at cloud perimeter boundaries, indirect prompt injection via tools, credential exfiltration defenses, and sandbox containment.

# Volume 08 - Security, Identity, and the Data Perimeter

Volume 08 - Security, Identity, and the Data Perimeter in the Cloud AI Engineering Zero to Godhood curriculum.

## Chapters

1. [Zero Trust Architecture in Hyperscale Clouds](Chapter_01_Zero_Trust_Architecture_in_Hyperscale_Clouds.md) - BeyondCorp architecture, identity-aware proxies, continuous session re-authentication, and micro-segmentation.
2. [Workload Identity Federation](Chapter_02_Workload_Identity_Federation.md) - Eliminating static service account keys, IRSA, EKS Pod Identity, GKE Workload Identity, and OIDC token exchange.
3. [Secrets Management and Dynamic Credentials](Chapter_03_Secrets_Management_and_Dynamic_Credentials.md) - AWS Secrets Manager and GCP Secret Manager mechanics, automated rotation lambdas, and HashiCorp Vault integrations.
4. [Encryption Key Hierarchies and Envelope Encryption](Chapter_04_Encryption_Key_Hierarchies_and_Envelope_Encryption.md) - Key Encryption Keys, Data Encryption Keys, hardware security modules, BYOK, HYOK, and cryptographic boundary defense.
5. [Software Supply Chain Security: SLSA and Sigstore](Chapter_05_Software_Supply_Chain_Security_SLSA_and_Sigstore.md) - SLSA level compliance, container image signing with Cosign, Rekor transparency logs, and admission controller enforcement.
6. [Constructing an Impenetrable Data Perimeter](Chapter_06_Constructing_an_Impenetrable_Data_Perimeter.md) - Coordinating SCP perimeter rules, S3 bucket policies, VPC endpoint policies, and VPC Service Controls perimeters.
7. [Compliance, Auditing, and Non-Repudiation](Chapter_07_Compliance_Auditing_and_Non_Repudiation.md) - SOC 2, FedRAMP, and HIPAA mapping, CloudTrail and Cloud Audit Logs immutable delivery, and cryptographic log validation.

# Developer Tooling & SysAdmin Foundations

> [!summary]
> Software engineering excellence requires mastery of developer productivity tooling, stream processing languages, modal text editors, and configuration management toolchains. This domain covers the foundational textbook on AWK by Aho, Kernighan, and Weinberg, Vincent Jousse's Vim guide, and modern DevOps configuration pipelines.

---

## Pillar Guides

1. **[[Developer-Tooling-and-SysAdmin|Developer Tooling & SysAdmin Practices]]**
   - *The AWK Programming Language (Alfred V. Aho, Brian W. Kernighan, Peter J. Weinberg, 1988)*: The definitive bible on stream processing, associative arrays, and pattern-action data transformations.
   - *Vim for humans (Vincent Jousse, 2015)*: Efficient modal text editing, movement verbs, buffers, and command ergonomics.
   - *DevOps Toolchain (UpGuard)*: Architecture of automated configuration, deployment pipelines, and compliance verification.
   - *SysAdmin Magazine: Tools & Tips for Security Admins (2016)*: Real-world administration scripts, automated log parsing, and forensic audit pipelines.

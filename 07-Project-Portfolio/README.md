# Project Portfolio Ideas

Building impressive projects is the best way to stand out. Here are "Gold Standard" project ideas for SDE and Quant roles.

## Software Engineering Projects

### 1. Load Balancer (C++ / Go)
*   **Concept:** Build a Layer 7 Load Balancer.
*   **Tech:** C++, Sockets, Multithreading.
*   **Features:** Round Robin algorithm, Health checks, Connection pooling.
*   **Why:** Shows networking and concurrency mastery.

### 2. Distributed Key-Value Store (Java / Go)
*   **Concept:** A simplified Redis clone.
*   **Tech:** TCP, Hash Maps, WAL (Write Ahead Log).
*   **Features:** `SET`, `GET`, `DEL`, Persistence, Replication.
*   **Why:** Demonstrates System Design knowledge (CAP theorem).

### 3. Real-Time Chat Application
*   **Concept:** Slack clone.
*   **Tech:** React (Frontend), Node.js/Go (Backend), WebSockets (Real-time).
*   **Features:** 1-on-1 chat, Group rooms, Message history.

## Quantitative Finance Projects

### 1. Limit Order Book and Matching Engine (C++)
*   **Concept:** The core of an exchange.
*   **Tech:** Modern C++, STL (`map`, `unordered_map`).
*   **Features:** Add/Cancel orders, Match Buy/Sell, Price-Time priority.
*   **Why:** #1 Project for HFT/Quant Dev roles.

### 2. Market Data Feed Handler (C++)
*   **Concept:** Parse and normalize financial data.
*   **Tech:** C++, Network Programming (UDP Multicast).
*   **Features:** Parse ITCH/FIX protocol messages, maintain book state.

### 3. Statistical Arbitrage Bot (Python)
*   **Concept:** Pairs Trading strategy.
*   **Tech:** Python, Pandas, Statsmodels.
*   **Features:** Co-integration test, Z-score calculation, Backtesting engine.

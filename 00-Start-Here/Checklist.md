# Progress Checklist

Copy this file and tick boxes as you go.
Durations are rough guides for focused study, not deadlines.

## Phase 1: Foundations (2 weeks)
- [ ] **Language:** master C++ (STL, RAII, move semantics) or Python (data model, generators).
- [ ] **CS basics:** OS (concurrency, threads), DBMS (SQL, indexing), networks (HTTP, TCP).
- [ ] **OOP:** practice SOLID principles (see `04-System-Design/01-LLD`).

## Phase 2: Data Structures and Algorithms (4 weeks)
- [ ] **Arrays and strings:** sliding window, two pointers.
- [ ] **Linked lists:** reversal, cycle detection.
- [ ] **Stacks and queues:** monotonic stack.
- [ ] **Trees and graphs:** BFS, DFS, Dijkstra, union-find.
- [ ] **DP:** knapsack, LCS, LIS.
- [ ] **Gold-standard patterns:** implement every file in `03-Data-Structures-Algorithms/04-Gold-Standard-Cpp-Patterns` from memory.
- [ ] **Practice:** solve the NeetCode 150.

## Phase 3: System Design (2 weeks)
- [ ] **Concepts:** scalability, load balancing, caching, the CAP theorem.
- [ ] **HLD:** design a URL shortener, a chat app, and a ride-sharing service.
- [ ] **LLD:** LRU cache, parking lot, and the core design patterns.

## Phase 4: Depth (pick at least one, 4+ weeks)
- [ ] **Distinguished engineering (`08`):** rebuild the lock-free stack, Raft, and the LSM tree yourself.
- [ ] **Performance (`12`, `15`):** reproduce false sharing, then profile and fix a leak.
- [ ] **Quant (`05`):** implement an order book in C++ and backtest a strategy in Python.
- [ ] **Low latency (`14`):** work through the 12-week production calibration roadmap.
- [ ] **Agentic AI (`13`):** build the agent loop from scratch, then add tools, memory, and evals.

## Phase 5: Career (1 week)
- [ ] **Resume:** polish using the guide in `06-Interview-Prep`.
- [ ] **Behavioral:** prepare 5 STAR stories.
- [ ] **Mock interviews:** practice with peers or a mock interview platform.
- [ ] **Pipeline:** set up the Interview Command Center (`16`) before applying.

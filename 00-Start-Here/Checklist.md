# Ultimate Interview Prep Checklist

Use this checklist to track your progress.

## Phase 1: Foundations (2 Weeks)
- [ ] **Language:** Master C++ (STL) or Python (Data Structures).
- [ ] **CS Basics:** Review OS (Concurrency, Threads), DBMS (SQL, Indexing), and Networks (HTTP, TCP).
- [ ] **OOP:** Practice SOLID principles (See `04-System-Design/01-LLD`).

## Phase 2: Data Structures and Algorithms (4 Weeks)
- [ ] **Arrays and Strings:** Sliding Window, Two Pointers.
- [ ] **Linked Lists:** Reversal, Cycle Detection.
- [ ] **Stacks and Queues:** Monotonic Stack.
- [ ] **Trees and Graphs:** BFS, DFS, Dijkstra, Union-Find.
- [ ] **DP:** Knapsack, LCS, LIS.
- [ ] **Practice:** Solve Top 150 LeetCode questions.

## Phase 3: System Design (2 Weeks)
- [ ] **Concepts:** Scalability, Load Balancing, Caching, CAP Theorem.
- [ ] **HLD:** Practice designing URL Shortener, Chat App, Uber.
- [ ] **LLD:** Practice LRU Cache, Parking Lot, Design Patterns (Singleton, Observer).

## Phase 4: Quant Specialization (Optional)
- [ ] **Math:** Probability, Statistics, Linear Algebra.
- [ ] **Finance:** Black-Scholes, Greeks, Arbitrage.
- [ ] **Coding:** Implement Order Book (C++), Backtest a Strategy (Python).

## Phase 5: Behavioral and Resume (1 Week)
- [ ] **Resume:** Polish using the guide in `06-Interview-Prep`.
- [ ] **Behavioral:** Prepare 3-5 STAR stories.
- [ ] **Mock Interviews:** Practice with peers or Pramp/Interviewing.io.

---
*Good luck. You have got this.*

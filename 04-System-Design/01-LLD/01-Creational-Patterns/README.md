# Creational Patterns

Creational patterns decide who is allowed to construct an object, and what that caller is not allowed to know.

- [[Factory-and-Abstract-Factory]] hides a concrete type behind a constructor that can grow a new variant.
- [[Builder-and-Prototype]] builds a complicated object in steps, or copies one you already configured.
- [[Singleton-and-Object-Pool]] controls how many instances exist, which is a resource decision and not a default.

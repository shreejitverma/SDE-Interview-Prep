# Structural Patterns

Structural patterns decide how two types sit together without becoming the same type.

- [[Adapter-Bridge-and-Facade]] changes a surface: an adapter matches a foreign API, a bridge splits abstraction from implementation, and a facade gives one door to a subsystem.
- [[Decorator-and-Proxy]] wraps an object: a decorator adds behavior, and a proxy controls access.
- [[Composite-and-Flyweight]] groups objects: a composite treats a tree as one node, and a flyweight shares the bytes that do not vary.

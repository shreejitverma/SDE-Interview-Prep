# Quantitative Finance Roadmap

Author: Shreejit Verma

## 🎯 Objective
Bridge the gap between Software Engineering and Financial Mathematics.

## 📚 Modules

### 1. Mathematics (The Foundation)
- **Probability & Statistics:** Distributions, Expectation, Variance.
- **Linear Algebra:** Eigenvectors, PCA (for factor models).
- **Calculus:** Stochastic Calculus (Itô's Lemma, Brownian Motion).

### 2. Quantitative Development (The Tech)
- **C++:** Templates, STL, Memory Management (Smart Pointers), Multithreading.
- **Low Latency:** Kernel bypass, FPGA basics, UDP/TCP multicast.
- **Python:** pandas, numpy, scipy, scikit-learn.

### 3. Algorithmic Trading (The Application)
- **Market Microstructure:** Order books, Matching engines.
- **Strategies:** Arbitrage, Mean Reversion, Momentum.
- **Backtesting:** Event-driven vs Vectorized.

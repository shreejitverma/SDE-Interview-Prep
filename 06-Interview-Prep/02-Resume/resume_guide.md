# Resume Building Tips for SDE & Quant

## General Rules
*   **One Page:** Unless you have 10+ years of experience.
*   **ATS Friendly:** Simple formatting, standard fonts, no icons/graphics.
*   **Action Verbs:** Start bullets with "Implemented", "Optimized", "Designed", "Led".

## Structure
1.  **Header:** Name, GitHub, LinkedIn, Email, Phone.
2.  **Education:** University, Degree, GPA (if good), Relevant Coursework.
3.  **Skills:**
    *   *Languages:* C++, Python, Java.
    *   *Tools:* Git, Docker, Linux, AWS.
    *   *Concepts:* DSA, System Design, Multithreading.
4.  **Experience:**
    *   Role, Company, Dates.
    *   *Bullet 1:* "Optimized [System X] using [Tech Y], reducing latency by [Z]%."
    *   *Bullet 2:* "Designed a scalable microservice for [Feature] handling [N] QPS."
5.  **Projects:**
    *   Name, Technologies used.
    *   "Built a High-Frequency Trading Order Book in C++ processing 10k orders/sec."

## Quant Specifics
*   Highlight **Math/Stats** coursework (Stochastic Calculus, Linear Algebra).
*   Showcase **C++ (Low Latency)** or **Python (Data Analysis)** projects.
*   Mention participation in Math Olympiads or Kaggle competitions.

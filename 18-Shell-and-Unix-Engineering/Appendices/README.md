# Appendices

Reference appendices for Shell and Unix Engineering: Zero to Godhood.
They are written last, from `solid` chapters, so every entry links to the chapter that explains and proves it.

- [Appendix A: Glossary of Shell and Unix Terms](Appendix_A_Glossary_of_Shell_and_Unix_Terms.md) - Precise definitions of the shell, terminal, process, and userland terms used across the curriculum.
- [Appendix B: Shell Feature Portability Map](Appendix_B_Shell_Feature_Portability_Map.md) - Which features POSIX sh, bash, zsh, dash, ksh93, mksh, yash, posh, and BusyBox ash support, verified by the lab matrix.
- [Appendix C: Userland Utility Differences](Appendix_C_Userland_Utility_Differences.md) - Flag-by-flag differences between the GNU, BSD and macOS, BusyBox, and uutils utilities.
- [Appendix D: Signals, Exit Codes, and Kernel Limits](Appendix_D_Signals_Exit_Codes_and_Kernel_Limits.md) - Signal numbers and default actions, exit code conventions, and the kernel limits scripts hit, on Linux and macOS.
- [Appendix E: ShellCheck Warning Index](Appendix_E_ShellCheck_Warning_Index.md) - The ShellCheck warnings that matter most, with the bug each one prevents and the chapter that explains it.
- [Appendix F: Expansion and Redirection Cheat Sheet](Appendix_F_Expansion_and_Redirection_Cheat_Sheet.md) - Every parameter expansion form and redirection operator on one page.
- [Appendix G: sed, awk, and jq Quick Reference](Appendix_G_Sed_Awk_and_Jq_Quick_Reference.md) - Commands, functions, and idioms for the three text languages.
- [Appendix H: Incident Response One-Liner Cookbook](Appendix_H_Incident_Response_One_Liner_Cookbook.md) - Tested one-liners for production triage, grouped by symptom.
- [Appendix I: Primary Sources and Reading List](Appendix_I_Primary_Sources_and_Reading_List.md) - Specifications, source trees, papers, and books, with why each one matters.
- [Appendix J: 16-Week Mastery Study Plan](Appendix_J_16_Week_Mastery_Study_Plan.md) - A week-by-week plan with readings, labs, and interview checkpoints.

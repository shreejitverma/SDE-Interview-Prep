# Drill: Audit a Gamed Developer Productivity Dashboard

> [!summary] Scope
> Owns an analytical engineering leadership drill evaluating telemetric data from an organization that tied performance bonuses to PR counts and raw deployment frequency.
> Reaches the Debug and Decide at Scale rungs by presenting telemetry data showing plummeting PR sizes, fractured PR chains, degraded review scrutiny, and surging change failure rates.
> Tasks the engineer with diagnosing Goodhart's Law pathologies and re-architecting the measurement system using the multi-dimensional SPACE and GSM frameworks.

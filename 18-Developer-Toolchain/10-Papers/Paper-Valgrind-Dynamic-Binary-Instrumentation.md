# Paper: Valgrind: Dynamic Binary Instrumentation (Nethercote and Seward 2007)

> [!summary] Scope
> Owns the seminal PLDI 2007 paper on Valgrind heavyweight dynamic binary instrumentation framework by Nicholas Nethercote and Julian Seward.
> Explains the Just-In-Time disassemble-and-resynthesize translation engine using VEX intermediate representation, shadow value tracking invariants, and plug-in tool architecture for Memcheck, Callgrind, and Helgrind.
> Contrasts dynamic binary instrumentation runtime overhead against compile-time sanitizer instrumentation.

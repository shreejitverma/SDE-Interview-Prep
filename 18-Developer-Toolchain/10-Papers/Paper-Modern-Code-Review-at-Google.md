# Paper: Modern Code Review: A Case Study at Google (Sadowski et al. 2018)

> [!summary] Scope
> Owns the ICSE-SEIP 2018 empirical study of 9 million reviewed changes at Google by Caitlin Sadowski et al.
> Analyzes review participation dynamics, turnaround latencies, change size distributions, and developer motivations.
> Demonstrates that Google introduced code review chiefly to keep code understandable and maintainable, with education and norm-keeping valued alongside defect prevention, grounding the code review and readability notes in pillar 09.

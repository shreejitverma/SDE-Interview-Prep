# Software Supply Chain Architecture Decision Records

> [!summary] Scope
> Evaluated trade-off matrices for supply chain security controls across enterprise engineering organizations.
> Compares SPDX 3.0 versus CycloneDX 1.7 for compliance and vulnerability management, ephemeral keyless Sigstore versus dedicated hardware HSM-backed keys, and consuming pre-compiled upstream binaries versus rebuilding all open-source dependencies from audited source code.
> Provides actionable guidance for staff and principal security architects.
> Documents implementation costs, operational friction, and security guarantees.

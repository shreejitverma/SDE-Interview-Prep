# Enterprise Architecture: Third-Party Code Ingestion and Quarantine

> [!summary] Scope
> High-scale reference architecture for safely consuming open-source software within regulated and high-security enterprise perimeters.
> Covers proxy registry quarantine queues, mandatory publication-age cooldown intervals, automated sandbox detonation for install scripts, federated differential source audits, and internal source rebuild pipelines.
> Defines automated gate criteria for promoting packages from quarantine to production repositories.
> Establishes governance policies for mitigating zero-day supply chain compromises.

# Git Email and Patch Workflows

> [!summary] Scope
> Owns asynchronous distributed patch generation, submission, and review over email protocols as practiced by the Linux kernel and Git upstream maintainers.
> Reaches Use and Explain rungs by covering git format-patch, git send-email, git am with three-way fallback, git range-diff across patch iterations, Message-ID threading, mailmap translation, and modern tools like b4.
> Delineates its boundary from forge-centric pull request workflows and web review systems.

# Git Branching Models, Merge Queues, and Code Review

> [!summary] Scope
> Owns team-level collaboration models, speculative integration pipelines, and code review structures.
> Reaches Use and Decide at Scale rungs by contrasting trunk-based development with GitFlow and release trains, implementing speculative merge queues that batch commits to prevent serial pipeline bottlenecks, configuring CODEOWNERS policies, and optimizing change size distributions.
> Leaves single-repo scaling and virtualized file systems to the monorepo note.

> [!summary] Scope
> Multi-platform binary wheel automation using cibuildwheel v4 across Linux container environments, macOS universal2, and Windows.
> Details environment configuration, build and skip selectors, platform repair hooks, and automated wheel testing within clean sub-environments.
> Bridges continuous integration matrix jobs with reproducible release publishing.
> Provides troubleshooting patterns for cross-compiling native extensions in CI runners.

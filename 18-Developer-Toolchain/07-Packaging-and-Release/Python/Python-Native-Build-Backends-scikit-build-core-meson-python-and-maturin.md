# Python Native Build Backends: scikit-build-core, meson-python, and maturin

> [!summary] Scope
> Comparative architecture and build execution of modern native C, C++, Fortran, and Rust build backends for Python packages.
> Covers scikit-build-core for CMake integration, meson-python for Meson and Ninja compilation, and maturin for PyO3-based Rust extensions.
> Evaluates build configuration, cross-compilation support, editable mode mechanics, and artifact repair pipelines.
> Guides selection of build backends based on existing native codebase architecture.
